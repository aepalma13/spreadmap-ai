
# 🧬 SpreadMap AI

An interactive educational simulator demonstrating how a fictional infection could spread through connected hospital areas.

## Features
- Interactive hospital floor map
- Adjustable contact and movement settings
- Infection spread timeline
- Scenario comparison
- AI-generated analysis

## Technologies
- Python
- Streamlit
- Plotly
- OpenAI API

## How to Run

Install the requirements:

pip install -r requirements.txt

Run the application:

streamlit run app.py

## Disclaimer

This project uses fictional data and simplified probabilities. It is an educational simulation, not a medical tool or a real hospital outbreak prediction system.
